十分钟运行 ​

先运行不依赖 GPU、数据集和模拟器的 dummy 闭环。它与真实任务共用 Runner、Harness、Agent、 VLN Job、ToolBus、评分和 Manifest 路径。

1. 准备运行环境 ​

项目要求 Python 3.10+。把 src/ 加入模块路径即可；脚本不绑定环境管理器：

bash
export PYTHONPATH="$PWD/src"
1

完整依赖清单保存在 config/conda/harnessvln.yaml，但使用何种 Python 环境由调用者决定。

2. 批量运行 Dummy Bench ​

bash
bash scripts/run_dummy.sh
1

等价的显式命令只有两份顶层配置：

bash
PYTHONPATH=src python -m harness.cli run \
  --runner config/runners/dummy_passthrough.yaml \
  --agent config/agents/passthrough.yaml
1
2
3

Runner 引用 dummy Bench，Bench 引用 dummy Env；Agent 配置内部引用 Dummy VLN。成功输出类似：

text
dummy_navigation/smoke: 2 cases, 0 task failures, 0 case errors, 0 bench errors, 0 cleanup errors, 0 output errors
/absolute/path/to/runs/dummy_passthrough/20260827T110258Z-73ed58b2-9085ad/manifest.json
1
2

Manifest v3 的 benchmarks[] 是 Bench summary 索引，完整配置和 Episode 结果分文件保存：

bash
RUN=$(find runs/dummy_passthrough -mindepth 1 -maxdepth 1 -type d | sort | tail -1)
jq '{status, aggregate_metrics, benchmarks}' "$RUN/manifest.json"
BENCH=$(jq -r '.benchmarks[0].path' "$RUN/manifest.json")
jq '{status, aggregate_metrics, case_counts, episodes}' "$RUN/$BENCH"
1
2
3
4

3. 单环境交互 ​

bash
bash scripts/run_dummy_interactive.sh
1

在 nav> 后输入导航指令。CLI 创建一次 Task，Agent 自己调用工具并以 nav.stop 结束该 Task； 随后 CLI 才接收下一条指令。输入 quit 退出会话。

4. 这两条链路的区别 ​

text
run: RunnerConfig -> BenchConfig[] -> EnvConfig
                         |                `-- execution tools
                         `-- cases + score
env: user instruction -------------> EnvConfig -> one Task
                    AgentConfig -> Agent + VLN? + Memory?
1
2
3
4
5

两者在进入 NavigationHarness.run_task 后完全一致。Runner 和交互 CLI 都不执行 observe -> predict -> step 循环。

bash
bash scripts/run_r2r_streamvln.sh
bash scripts/run_r2r_janusvln.sh
bash scripts/run_r2r_dualvln.sh

bash
PYTHONPATH=src python -m harness.cli run \
  --runner config/runners/r2r_streamvln.yaml \
  --agent config/agents/passthrough_streamvln.yaml

2

DualVLN 的 -30° RGB-D profile 已由 r2r_ce_dualvln.yaml 引用专用 Env，不需要在命令行叠加。 真实运行仍要求对应数据、场景、checkpoint、上游源码与 GPU 已按配置落地；验证等级见 兼容与验证矩阵。
