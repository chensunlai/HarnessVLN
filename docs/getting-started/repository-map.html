仓库地图 ​

仓库不使用 src/harnessvln/ 的额外安装层。运行时把根目录下的 src/ 放入 PYTHONPATH， 一级目录直接表达模块职责。

text
HarnessVLN/
├── src/
│   ├── harness/       # 运行时、ToolBus、配置、Runner、Output、CLI
│   ├── schemas/       # 跨插件的最小导航数据类型
│   ├── agents/        # Agent 公共辅助 + 每个 Agent 独立子目录
│   ├── vln/           # 共享 RPC 基础设施 + 每个 VLN 独立子目录
│   ├── envs/          # 每个模拟器/真机中间件独立子目录
│   ├── benches/       # Bench 基座 + 每个数据集独立子目录
│   └── memory/        # 每个空间记忆独立子目录
├── config/
│   ├── agents/ envs/ vln/ benches/ memory/ runners/
│   └── conda/harnessvln.yaml
├── scripts/           # 固定组合的可执行入口
├── tests/
│   ├── unit/          # 局部行为与竞态
│   ├── contract/      # 数据、模型配置、trace 契约
│   └── integration/   # 从 YAML 运行的闭环 smoke
├── docs/              # GitHub Pages 生产静态站点
├── data/              # 数据集、场景与资产；可含软链接
├── model/             # 模型 checkpoint
├── cache/             # 上游源码与可再生缓存，不提交
└── runs/              # Run/Bench/Episode 结果、视频与 Memory，不提交

从入口向内阅读 ​

推荐按调用关系而不是字母顺序阅读：

  1. harness/cli.py：选择 run 或 env 模式，解析两份顶层 YAML。
  2. harness/app.py：解析引用图、构造 StackFactory、Runner/交互会话并写 Manifest。
  3. harness/runner.py：有界调度完整 Task。
  4. harness/runtime.py：单 Task 生命周期与终止竞争。
  5. harness/tool_bus.py：能力注册、权限、校验、写屏障与审计。
  6. harness/output.py / video.py：分层作用域、结构化文件和媒体关闭。
  7. harness/contracts.py：四类核心插件的最小 Protocol。

再根据改动方向进入 agents/、vln/、envs/、benches/ 或 memory/。

基座与插件的目录边界 ​

二级领域目录中的 Python 文件只放公共基座，例如 benches/base.py、agents/_jobs.py、 vln/rpc.py 和 vln/worker.py。所有具体插件必须再进入一个独立子目录，即使当前只有一个实现文件：

│   └── dummy_landmark/{__init__.py, memory.py}

为什么每个插件必须有子目录 ​

src/vln/streamvln/、janusvln/、dualvln/ 各自拥有 navigator 与 worker；Agent、Environment、 Bench 和 Memory 遵循同一规则。这样插件未来增加预处理、资源管理、协议适配或测试辅助时无需再次 搬迁，也不会把不同实现堆到共享条件分支文件中。

配置不是代码注册表 ​

YAML 通过 module:object factory 指向可调用对象，例如：

yaml
agent:
  factory: agents.passthrough:PassthroughVLNAgent
  params:
    poll_period_s: 1.0
  vln: ../vln/streamvln.yaml

增加插件通常无需修改中央枚举。稳定的是 Protocol、schema 与工具名字，具体实现由配置加载。

不应放进仓库的内容 ​

cache/、模型/数据软链接、运行产物和根目录普通文件受 .gitignore 约束。可复现信息应进入配置 中的 provenance、紧凑 trace 或文档；大型 checkpoint、完整 manifest 和模拟器缓存保留在本地。
