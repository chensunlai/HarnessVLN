新组合的验收门槛 ​

  1. profile/requirements 静态通过；
  2. task modality 与模型训练/输入契约匹配；
  3. loader 无真值泄漏；
  4. 真实 reset-observe-act-finish-stop；
  5. timeout/cancel 后无进程、文件和运动残留；
  6. 固定小样本 trace 可复核；
  7. 同版本完整 split 与官方 evaluator 对照。

前两项只能证明可以尝试运行；第 7 项才支持对外声称完成 benchmark 兼容。
