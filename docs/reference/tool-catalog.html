nav.move.discrete ​

执行一个完整高层离散动作，写工具。

json
{"action": "forward"}
1

action 的 enum 来自当前 Environment，例如 R2R 是 forward/turn_left/turn_right，Dual overlay 增加 stand_still。返回至少表达 accepted/action，其他计数、native tick 或反馈由 adapter 扩展。

nav.goal.finish ​

提交当前 Goal，写工具。

nav.stop ​

结束完整 Task，写工具，由 Harness 注册且归 Agent 所有。

json
{"status": "completed", "reason": "all navigation goals completed"}
1

返回最终获胜 terminal 的 status/reason。多个并发 stop 中第一个 claim 生效。VLN navigator 被明确 禁止把 nav.stop 声明为 required tool。

vln.navigate.local ​

执行一个局部可视 VLN 段，写工具，并阻塞到本段结束。

json
{"instruction": "Move through the visible doorway straight ahead."}
1

instruction 必须基于最新 nav.observe，只描述一个可见目标，不能复制完整 Bench 指令、描述不可见 房间或串联多个 waypoint，最长 256 字符。Agent 不提供步数；navigator 的 local_max_steps 保证 物理执行范围有界。返回：

json
{"state": "succeeded", "reason": "model emitted STOP"}
1

state 使用 succeeded、failed 或 cancelled，实现可增加 steps 等字段。返回后 Agent 应重新观察， 再决定下一段或提交 Goal。

vln.navigate.task ​

把完整任务指令交给 VLN 并阻塞到结束，写工具。

json
{"instruction": "walk past the sofa and enter the kitchen"}
1

该工具只用于 PassthroughVLNAgent 评测端到端 VLN 原始能力，不进入 NormalAgent 白名单。内部 Job id、status 与 cancel 由 navigator 管理，不暴露给 Agent 模型。
